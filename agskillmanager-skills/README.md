# AG Skill Manager Agent Skills

Two portable skills:

- `agskillmanager`: integrate, configure and debug governed Skill workflows.
- `agskillmanager-extend`: implement and verify async extension points.

```console
npx skills add smuniharish/agskillmanager --skill agskillmanager
npx skills add smuniharish/agskillmanager --skill agskillmanager-extend
```

Alternatively copy the desired skill directory into your agent's supported
workspace skill directory. Keep SKILL.md, references, scripts, assets and evals together.
See [validation](validation/README.md).
