# Troubleshooting

- Missing discovery: inspect lifecycle, filters and source errors.
- Approval not retained: reuse durable feedback and registry storage.
- Missing capability: register/refresh MCP servers and use exact names or IDs.
- PostgreSQL on Windows: use an asyncio SelectorEventLoop.
- Optional import failure: install the named extra.
- Telemetry absent: inspect bounded observability errors and actual backend ingestion.
- Conflict: create a new revision ID; do not mutate immutable content.
