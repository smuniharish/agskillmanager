# Skill Manager Agent Skills

Two portable skills:

- `skill-manager`: integrate, configure and debug governed Skill workflows.
- `skill-manager-extend`: implement and verify async extension points.

```console
npx skills add smuniharish/skill-manager --skill skill-manager
npx skills add smuniharish/skill-manager --skill skill-manager-extend
```

Alternatively copy the desired skill directory into your agent's supported
workspace skill directory. Keep SKILL.md, references, scripts, assets and evals together.
See [validation](validation/README.md).
